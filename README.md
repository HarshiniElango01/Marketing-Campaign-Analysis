# Marketing Campaign Performance Analysis

## Project Overview
This project analyzes marketing campaign data to evaluate campaign effectiveness, customer behavior, and ROI.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data Cleaning & Preprocessing
- Campaign Performance Analysis
- ROI Analysis
- Customer Segmentation
- Machine Learning Model (Prediction)

## Dataset
Dataset is loaded via Google Drive link for easy access.

## How to Run
Open the notebook in Google Colab and run all cells.
